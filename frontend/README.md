# PawCats

Aplicación web para apoyar la adopción responsable de gatitos rescatados.

## Tecnologías utilizadas

- React
- Vite
- TypeScript
- Bootstrap
- React Router
- Atomic Design

## Funcionalidades

- Página de inicio.
- Catálogo de cuatro gatitos.
- Fotografías de cada gatito.
- Detalle dinámico mediante una ruta con identificador.
- Navegación entre Inicio, Adopciones, Servicios y Contacto.
- Formulario de contacto con validación de nombre y correo.
- Diseño adaptable para distintos tamaños de pantalla.
